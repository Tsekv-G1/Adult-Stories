# Adult Stories 8.6.0 — бүтэн final багц

Энэ багцад CTA, Telegram, төлбөрийн харагдац, хэрэглэгчийн бүртгэл болон өмнөх цэвэрлэгээний бүх засвар орсон.

## Deploy

ZIP-ээ задлаад доторх файлуудыг Adult Stories repository-ийн үндсэн түвшинд ижил замаар нэмж/солино. Root дээр `netlify.toml`, `package.json`, `public/`, `netlify/`, `server/`, `scripts/` шууд харагдана. `.git`-ийг хадгална. Netlify Environment variables, Supabase өгөгдөл болон R2 bucket-уудыг устгахгүй.

| Netlify тохиргоо | Утга |
| --- | --- |
| Base directory | Хоосон |
| Build command | `npm run build` |
| Publish directory | `public` |
| Functions directory | `netlify/functions` |
| Node | 22 |

Build нь хуучин bundle-уудыг цэвэрлэж, импорт болон HTML asset-ууд, FFmpeg binary-г шалгаад шинэ bundle үүсгэнэ. `public/deployment.json` дахь version нь package.json-тай таарна. Файлуудыг дангаар нь сонгож орхихын оронд бүтэн багцыг ашиглана.

## Одоогийн тохиргоог хадгална

Энэ шинэчлэлтэд шинэ SQL, шинэ Environment variable шаардлагагүй. Шинээр суулгаж байгаа бол `supabase/` дахь schema болон migration-уудыг шалгана; ажиллаж буй санг reset хийхгүй.

Хэрэглэж буй үйлчилгээний тохиргоо: `APP_ORIGIN`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, R2-ийн `R2_ACCOUNT_ID` эсвэл `R2_ENDPOINT`, `R2_MEDIA_BUCKET`, `R2_AUDIO_BUCKET`, `R2_PUBLIC_BASE_URL`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`. Төлбөрийн мэдээлэл: `PAYMENT_BANK`, `PAYMENT_ACCOUNT`, `PAYMENT_ACCOUNT_NAME`; шаардлагатай бол `PAYMENT_IBAN`, `SUPPORT_CONTACT`. Telegram: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Одоо байгаа утгуудыг хэвээр хадгална; нууц түлхүүрийг public файлд оруулахгүй.

`audio-worker/` нь тусдаа Docker/Hugging Face worker. Өмнөх worker deploy-г хэвээр хадгална. Netlify-ийн preview тайрах урсгал нь `editor-audio-crop-background` болон FFmpeg ашиглана.

## CTA ба preview

- R2 сангийн хувийн болон нийтийн аудиогоос CTA сонгоно.
- Өгүүллэгийн CTA эсвэл IN/OUT өөрчлөөд Хадгалах дарахад шинэ preview бэлтгэнэ. CTA хэсгийн бэлтгэх/шинэчлэх товчоор мөн ажиллуулна.
- Preview + сонгосон завсар (анхдагч 1.5 секунд) + CTA нь нэг MP3 файл болно. Дутуу үр дүнг бэлэн гэж хадгалахгүй.
- «Бүх өгүүллэгт хэрэглэх» нь өмнө нь бэлтгэсэн preview-үүдийг ч шинэчилнэ. Хуучин CTA-г солино; давхар залгахгүй. Ижил URL, ижил завсартай бэлэн preview-г дахин үүсгэхгүй.
- Нийтлэг CTA-ийн URL болон завсар хамт хадгалагдаж, шинэ өгүүллэгт үйлчилнэ.
- Бүх өгүүллэгийн шинэчлэлт дуусах хүртэл админ табыг нээлттэй байлгана. Эхэлсэн файл сервер дээр дуусна; үлдсэн дараалал ижил browser/site дээр админд дахин ороход үргэлжилнэ. Browser хадгалалт хориглогдсон бол явцыг сэргээх боломжгүйг UI мэдэгдэнэ.
- Файл үүссэн ч өгүүллэгт хадгалах хүсэлт бүтэлгүйтвэл ажлын мэдээллийг хадгалж үлдээнэ. Ижил файлыг дахин боловсруулахгүйгээр хадгалалтаа дахин оролдож болно.
- Өгүүллэг өөр цонхноос өөрчлөгдвөл bulk ажил түүнийг дарж бичихгүй. Алдаатай өгүүллэгийг явцын хэсэгт харуулна.

## R2 цэвэрлэгээ

24 цаг тутам устгадаг хуваарь байхгүй. Бүх өгүүллэгийн шинэчлэлт дуусахад эсвэл «Хуучин preview цэвэрлэх» дарахад шалгана.

Эхлээд ашиглагдахгүй болсон generated preview-г тэмдэглэнэ. Тэмдэглэснээс хойш дор хаяж 24 цаг өнгөрсөн, одоо ч өгүүллэг/нийтлэг тохиргоо/медиа/хувийн агуулгад ашиглагдаагүй, идэвхтэй render байхгүй үед л устгана. Дахин ашигласан бол хүлээлтийн тэмдэглэгээг цуцална. Ажиллаж буй public preview, бүтэн аудио, CTA эх файл болон зургийг цэвэрлэхгүй.

## Төлбөр ба Telegram

Төлбөр мэдүүлсэн, баталсан, татгалзсан Telegram мэдэгдэлд нэр, утас, 7/30 хоногийн эрх болон дүн харагдана. Богино захиалгын ID-г харуулахгүй. Нэр оруулаагүй бол утас нь хэрэглэгчийг танина. Хуучин Telegram мэдэгдлүүд өөрчлөгдөхгүй. Telegram холболтын алдаа нь төлбөр баталгаажуулалтыг буцаахгүй.

Billing нь тохируулсан анхны үнэ, төлөх үнэ, хямдралын хувь, хэмнэх дүнг харуулна. Анхны худалдан авалтын нөхцөл тусдаа харагдана. Миний бүртгэл нь идэвхтэй эрх, дуусах хугацаа, үлдсэн хоногийг Улаанбаатарын цагаар харуулна; захиалгын түүх харуулахгүй.

## Шалгалт

`npm test` нь төлбөр, нэвтрэлт, Telegram, CTA нэгтгэл, давхар хүсэлт, сэргээх урсгал болон storage хамгаалалтыг шалгана. `npm run build` нь source, хамаарал, asset болон FFmpeg-ийг шалгана. `npm run test:browser` нь Playwright browser суусан орчинд ажиллана.

Тестүүд нь гаднын API-г mock ашиглан шалгана. Production дээрх бодит банк, Telegram хүргэлт, R2 permission/CORS болон Netlify-ийн environment утгуудыг энэ багц дангаараа батлахгүй.

Багцын шалгалт: production build амжилттай; 91 тест бүгд давсан; Netlify-ийн 3 function bundle болон handler export шалгагдсан; audio-worker Python syntax шалгагдсан. Public файлуудаас service-role JWT болон Telegram bot token илрээгүй. Энэ орчинд Chromium browser байхгүй тул browser smoke тест болон бодит production үйлчилгээний шалгалт хийгдээгүй.
